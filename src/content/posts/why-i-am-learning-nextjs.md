I started with WordPress, PHP and WooCommerce. I still like them. But most remote job posts for React developers also ask for **Next.js**, so this site is my first Next.js project.

## What I like so far

- **File-based routing:** `app/blog/[slug]/page.tsx` becomes `/blog/my-post/`.
- **Server Components:** the blog posts are read from Markdown files at build time. No database, no API.
- **Static export:** `output: 'export'` produces plain HTML files, so I can host the site for free on GitHub Pages.

## What WordPress taught me that still helps

Templates, content types, SEO basics, and how clients actually edit content. The same ideas exist in Next.js — just in code instead of an admin panel.

## The plan

My roadmap has 10 projects, ending with a full-stack SaaS. Every project is public on GitHub, so you can see the real code.
